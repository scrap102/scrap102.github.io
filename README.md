# MINISLOP 88

Играбельный веб-прототип текстовой игры про кейсы, крафт и экспедиции в
Неевклидову канализацию. Без сборки, без зависимостей — чистые HTML/CSS/JS.

## Структура проекта

```
index.html   — разметка страницы, подключает style.css и game.js
style.css    — все стили
game.js      — данные игры, боевой движок и весь UI-слой
README.md    — этот файл
```

Один файл `game.js` содержит всё: справочники предметов/юнитов/рецептов,
боевую систему, механику экспедиций и рендеринг интерфейса. Это сделано
осознанно (проще диффать один файл на раннем этапе прототипа), но при
желании его несложно разрезать на модули (`data.js`, `engine.js`, `ui.js`)
— в коде уже есть соответствующие секции-комментарии
(`// ===== DATA =====`, `// ===== GAME STATE =====`,
`// ===== APP / DOM LAYER =====` и т.д.), по которым видно, где резать.

## Как запустить локально

Это статический сайт без сборки — достаточно любого способа раздать три
файла по HTTP:

```bash
# из папки проекта
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

Также подойдёт расширение VS Code "Live Server" или любой другой локальный
статический сервер.

**Открыть index.html двойным кликом (протокол file://) тоже в целом
работает**, но в некоторых браузерах `localStorage` (см. ниже) в режиме
file:// ограничен или недоступен — тогда сохранение прогресса между
перезагрузками может не работать. Если это важно, лучше поднять локальный
сервер, как выше.

## Сохранение прогресса

Игра сохраняет прогресс (валюту, инвентарь, юнитов, историю кейсов) в
`localStorage` браузера — автоматически, без кнопок. Это значит:

- Сохранение привязано к конкретному браузеру и домену/пути. У каждого
  посетителя будет свой собственный прогресс.
- Очистка данных сайта в браузере (или приватная/инкогнито-вкладка)
  обнулит прогресс.
- Сохранение не будет работать поверх изначально существовавшей заглушки
  для `window.storage` — если вы видите в коде обращения к `window.storage`,
  это следы среды, где создавался прототип (Claude.ai); для обычного
  браузера код автоматически использует `localStorage` (см. функции
  `storageGet` / `storageSet` в `game.js`).

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и запушьте туда эти три файла (или всю
   папку целиком).
2. В репозитории: **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Source: Deploy from a
   branch**, затем ветку (обычно `main`) и папку `/ (root)`.
4. Сохраните — через минуту-две сайт будет доступен по адресу вида
   `https://<ваш-логин>.github.io/<репозиторий>/`.

Настраивать больше ничего не нужно: сборки нет, зависимостей нет, все пути
в `index.html` относительные.

## Известные ограничения текущего прототипа

- Картинок нет — вместо иллюстраций юнитов и предметов используются эмодзи
  и текстовые описания. Это осознанное решение на время, пока не готов
  визуальный скелет.
- Флаг `TESTING_INFINITE_IO` в `game.js` (ищите его рядом с функциями
  `canAffordIo`/`spendIo`) сейчас включён — Ио не тратится ни на что. Когда
  захотите вернуть нормальную экономику, поставьте `TESTING_INFINITE_IO = false`.
- Контент, которого не было в исходных заметках и который придумал
  Claude, помечен символом `*` в названии — юниты, предметы и рецепты.
- Реализована только локация «Неевклидова канализация», Большой/Мех/Говна-кейсы,
  Лавка Мартына и Казино Крипто-Джокера; вторая локация (Туманные земли/Farlands)
  и Алхи-кейс — в исходных заметках, но пока не реализованы.
- Валюта АР (для казино) добывается только через обмен у Диогена (в экспедиции,
  за Бочку) и редкий бонус за победу над Евклидом — стартовый запас всегда 0.

## Технические детали для разработчиков

- Чистый vanilla JS, без фреймворков и сборщиков.
- Рендеринг — через полную перерисовку `innerHTML` активной вкладки при
  каждом изменении состояния (см. `renderAll()` в конце `game.js`).
- Перетаскивание юнитов/компонентов — нативный HTML5 Drag and Drop API,
  с запасным вариантом «клик, затем клик по цели» для тач-устройств и
  на случай проблем с DnD.
- Шрифты подключены через `@import` из Google Fonts в начале `style.css`
  (Special Elite, Inter, IBM Plex Mono) — требуется интернет при первой
  загрузке страницы.
